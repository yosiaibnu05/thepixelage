# Frontend Technical Test – Animated Hero Section

## 🔗 Live Demo
You can view the live version hosted at:  
👉 [https:/ibnu.fun/](https://ibnu.fun/)

This project is a technical test implementation of a modern, animated single-page section using:

- **Next.js** with React and TypeScript
- **GSAP** for scroll-based animations
- **Lenis** for smooth scroll interactions
- **Lottie** for vector animation rendering

### ✨ Key Features

- Word-by-word text reveal animation
- Scroll-triggered parallax effects
- Smooth, custom scroll behavior with Lenis
- Responsive layout design
- Clean and maintainable code using modern React hooks

This test demonstrates frontend skills in animation performance, scroll interaction, and UI composition.
